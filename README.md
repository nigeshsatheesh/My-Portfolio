# Nigesh's Portfolio

This is my personal portfolio showcasing my skills, projects, and journey as an Artificial Intelligence & Data Science engineering student. The site is built around an authentic creative design consisting of brushstroke elements and interactive web content.

**Live site:** https://www.nigeshsatheesh.com

---

## About the Project

I am a B.Tech student specializing in Artificial Intelligence & Data Science at Sri Krishna College of Engineering and Technology, Coimbatore, with a career focus on Data Science, followed by Machine Learning and Full Stack Development. This portfolio presents my work to recruiters, collaborators, and peers, and doubles as a hands-on project for applying full-stack web development concepts as I learn them.

## Sections

| Section | Description |
|:---|:---|
| **Home** | Homepage of my portfolio featuring navigation links and a hero section. |
| **About** | Introduction to my background, education, and interests. |
| **Skills** | Overview of my programming languages, tools, and technologies. |
| **Works** | Interactive stacked project cards. Clicking the top card sends it to the back, revealing the next project. |
| **Journey** | Timeline showcasing my education, internships, coursework, and milestones. |
| **Contact** | Contact information and ways to get in touch. |

## Design Highlights

- Fonts Utilized 
    - **Cabin**
    - **Host Grotesk**
    - **Space Grotesk**
- Authentic design using brushstrokes
    - Brushstroke **Spaghetti Western**
- Creamy and dark colour themes
    - Color Palette **`#FBF7F4` `#E5DFD3` `#A39383` `#675D54` `#232323`**
- Interactive journey timeline SVG
- Layered SVG brushstroke animation, revealed using SVG mask path with a rounded leading edge
- Stacked, animated project cards with click-to-cycle interaction built using JS
- Responsive layouts across laptop, tablet, and mobile viewports without altering the core visual design

## Tech Stack

**Current**

- HTML5
- CSS3 (custom styles, animations, responsive design)
- JavaScript (brushstroke animation, card animation, regex based validation, EmailJS)
- Bootstrap 5.3.3 (via CDN)
- Git and GitHub for version control
- Figma for UI/UX design

## Responsiveness

The layout was designed first for laptop viewports and then adapted to smaller screens using media queries, covering common phone and tablet sizes while keeping the desktop layout unchanged.

**The design was created for desktop, so the site is best experienced on a desktop.**
