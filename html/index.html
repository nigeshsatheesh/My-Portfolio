TRACE
LinkedIn GitHub
TRACE is an AI-powered traffic monitoring and enforcement system that connects multiple CCTV cameras to track vehicles across city roads. It detects vehicles and recognizes license plates using YOLOv8 and PaddleOCR, then combines visual features and spatio-temporal analysis to reconstruct vehicle journeys across cameras. It identifies suspicious movements, impossible journeys, and duplicate plates while generating real-time alerts for blacklisted vehicles. It also provides interactive GIS maps, traffic heatmaps, and congestion analytics to help authorities monitor traffic and make informed decisions.

WIS
LinkedIn GitHub
EcoGuard - Wildlife Intelligence System (WIS) is an AI-powered wildlife monitoring platform that combines image-based species recognition and bioacoustic classification to support wildlife conservation. It uses MobileNetV2 for image classification and combines YAMNet and Google Perch 2.0 audio embeddings to identify wildlife species from sounds. The system provides wildlife observation, population analysis, geographic insights through the GBIF API, and automated PDF reporting. Built using MERN stack, Python/Flask ML services, it is deployed across AWS Amplify, Render, Google Cloud Run, and MongoDB Atlas.

InsightEd is a Bluetooth Low Energy (BLE)-based attendance system that automates classroom attendance using student smartphones and an ESP32 scanner. The Android application advertises a unique service UUID for student identification, while the ESP32 detects nearby devices and records attendance in Firebase Database. InsightEd provides an automated classroom attendance solution.
